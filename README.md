# 토익 공부 (개인용 PWA)

아이폰 홈 화면에 까는 토익 공부 앱. 단어 복습(SM-2) · 강의 복습 퀴즈 · 토익 파트 2 듣기 · 오답 노트.
문제와 예문은 Claude(`claude-opus-5-5`)가 만들고, 모든 기록은 폰 안에만 저장됩니다.

## 아이폰에 설치

1. 아이폰 **사파리**로 앱 주소를 엽니다.
2. 아래 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면의 "토익" 아이콘으로 엽니다.

## 처음 한 번

1. **설정 → Claude API 키**: 키를 붙여 넣고 저장. 키는 이 폰에만 저장되고 백업에도 안 들어갑니다.
2. **설정 → 엑셀 불러오기**: 단어 엑셀(첫 줄 `Day / 단어 / 뜻`)을 아이폰 "파일" 앱(iCloud Drive)에 넣어 두고 고릅니다.
3. **강의 → 목차 사진 고르기**: 인강 목차 캡처를 올리면 Claude가 강 번호·제목을 읽습니다.

## 매일

- 홈 "오늘 할 일"을 위에서부터 누르면 됩니다.
- 인강을 다 들었으면 **강의 → 그 강 [끝냄]** → 복습 퀴즈 5문제가 만들어집니다.
- 인터넷이 될 때 퀴즈·듣기·예문을 미리 받아 두므로 지하철 터널에서도 계속 풀 수 있습니다.
- 일주일에 한 번 **설정 → 백업 내보내기**로 "파일"에 저장해 두세요.

## 개발

```bash
npm install
npm test
VITE_MOCK_CLAUDE=1 npm run dev   # 진짜 키 없이 가짜 Claude 로 화면 확인
npm run build
```

단어 엑셀은 저작권 때문에 저장소에 넣지 않습니다(`.gitignore`의 `*.xlsx`).
배포: `develop` 브랜치에 push 하면 GitHub Actions 가 GitHub Pages 로 올립니다.
